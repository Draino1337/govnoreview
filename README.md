# govnoreview

Сравнение смартфонов: характеристики, бенчмарки, автономность и камеры бок о бок.

**Сайт:** https://draino1337.github.io/govnoreview/

## Что умеет

- Поиск телефона с автодополнением (работает и по-русски: «самсунг», «айфон», «поко»), управление с клавиатуры.
- Страница сравнения двух моделей: ключевые отличия, оценки по категориям с радаром и итоговая оценка.
- Changelog на главной: какие смартфоны и когда появились на сайте; клик по модели ставит её в сравнение.
- Рейтинг (`#/rating`): пьедестал и места всех моделей, общий топ и топы по категориям.
- Индекс «цена/качество» — введите актуальные цены, значение пересчитывается сразу.
- Таблица характеристик с подсветкой победителя в каждой строке, фильтр «только отличия» и поиск по параметрам.
- Бенчмарки, автономность и зарядка, камеры по объективам.
- Каждый телефон показан одним кадром: экран лежит поверх спины, видно сразу обе стороны. Это вырезки с прозрачным фоном, они наклоняются за курсором.
- Главный экран статичный и умещается в одно окно: заголовок и выбор двух телефонов.
- Светлая и тёмная темы, адаптивная вёрстка, ссылка на сравнение копируется одной кнопкой.

## Запуск

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # данные → типы → сборка в docs/
npm run preview    # посмотреть собранный сайт
```

Сайт отдаётся GitHub Pages прямо из папки `docs/` ветки `govnoreview`, маршруты — hash-ссылки (`#/compare/…`), поэтому серверных редиректов не нужно.

## Данные

Характеристики и замеры лежат в `research/tsv/*.tsv`, скрипт `scripts/build-data.mjs` собирает из них `src/data/phones.json`.
Чтобы добавить телефон: положите выгрузку в `research/tsv`, опишите пару телефонов в `PAGES` (id, бренд, название, цвет и раскладка камер для запасной «нарисованной» панели) и запустите `npm run data`. Сенсоры камер (основная, сверхширокоугольная, телевик) берутся из `research/sensors.tsv`: собраны с nanoreview, пробелы — с Kimovil; «не раскрыт» — модель сенсора нигде не названа. Картинки чипов: строка «чип|ссылка» в `research/chips.tsv`, затем `node scripts/chip-images.mjs` кладёт их в `public/chips/`; `npm run data` предупредит, если картинки нет.

В каталоге сейчас 283 модели 16 брендов: Apple, Samsung, Google, Xiaomi, Huawei, Honor, Nothing, OnePlus, Vivo, Oppo, Asus, ZTE, Motorola, Realme, Sony и Fairphone. Данные собраны из открытых источников (в первую очередь со страниц сравнений NanoReview, для старых Pixel — с GSMArena, а также Geekbench, AnTuTu, 3DMark) по состоянию на ноябрь 2026.

## Фото телефонов

Каждый телефон показан одним кадром `public/phones/<id>.webp` (id — как в `src/data/phones.json`): экран лежит поверх спины. Сейчас все кадры — готовые композиции, присланные владельцем сайта: `node scripts/user-photo.mjs <папка>` чистит их и кладёт в `research/parts/<id>-user.webp`, `node scripts/combine.mjs` собирает кадр сайта, `npm run data` обновляет данные и делает миниатюры для списков в `public/phones/sm/`. Запасной вариант — сборка из галерей Kimovil (`node scripts/kimovil.mjs`). Откуда взята каждая вырезка и как собран каждый кадр — в [research/photo-sources.md](research/photo-sources.md). Изображения принадлежат их производителям.

Во всех кадрах спина слева, а экран лежит поверх неё справа и закрывает четверть спины. Где у Kimovil нет прямого снимка спины, берётся его готовая композиция «спина + экран» с тем же расположением.

```bash
# заменить кадры присланными PNG («<бренд> <модель>.png»)
node scripts/user-photo.mjs <папка или файлы …>
# скачать снимки Kimovil и сделать вырезки (по умолчанию — все телефоны из таблицы в скрипте; можно перечислить id)
node scripts/kimovil.mjs [id …]
# собрать единый кадр
node scripts/combine.mjs [id …]
# контактный лист из нескольких кадров, чтобы выбрать нужный: <файл> <колонок> <ширина> <высота> <кадры…> («-» — пустая ячейка)
node scripts/make-sheet.mjs лист.png 6 260 280 кадр1.png кадр2.png
```

Скачанные исходники держите в `research/img-src/` — эта папка не попадает в git. После сборки кадров запустите `npm run build`: отношение сторон кадра (`photo`) в данных обновится само, а телефон без кадра рисуется запасной задней панелью.

## Как считаются оценки

Оценки по шести категориям и итог считаются в браузере из характеристик и замеров (`src/lib/score.ts`).
Это автоматическая модель, а не экспертное мнение. Камера оценивается по DxOMARK (`research/dxomark.tsv`), а где DxOMARK телефон не тестировал — по характеристикам и году выхода.
Проект не связан с производителями и сайтами-источниками.
