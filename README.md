# govnoreview

Сравнение смартфонов: характеристики, бенчмарки, автономность и камеры бок о бок.
Интерактивные оценки пересчитываются под ваш сценарий — универсальный, игры, камерафон, мультимедиа, автономность.

**Сайт:** https://draino1337.github.io/govnoreview/

## Что умеет

- Поиск телефона с автодополнением (работает и по-русски: «самсунг», «айфон», «поко»), управление с клавиатуры.
- Страница сравнения двух моделей: ключевые отличия, оценки по категориям с радаром, итог под выбранный сценарий.
- Индекс «цена/качество» — введите актуальные цены, значение пересчитывается сразу.
- Таблица характеристик с подсветкой победителя в каждой строке, фильтр «только отличия» и поиск по параметрам.
- Бенчмарки, автономность и зарядка, камеры по объективам.
- Каждый телефон показан двумя видами — сзади и спереди: переключатель «Спереди / Сзади» или клик по телефону переворачивает карточки. Это вырезки с прозрачным фоном, они наклоняются за курсором.
- Главный экран статичный и умещается в одно окно: заголовок и выбор двух телефонов.
- Светлая и тёмная темы, адаптивная вёрстка, ссылка на сравнение копируется одной кнопкой.

## Запуск

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # данные → типы → сборка в docs/
npm run preview    # посмотреть собранный сайт
```

Сайт отдаётся GitHub Pages прямо из папки `docs/` ветки `govnoreview`, маршруты — hash-ссылки (`#/compare/…`), поэтому серверных редиректов не нужно.

## Данные

Характеристики и замеры лежат в `research/tsv/*.tsv`, скрипт `scripts/build-data.mjs` собирает из них `src/data/phones.json`.
Чтобы добавить телефон: положите выгрузку в `research/tsv`, опишите пару телефонов в `PAGES` (id, бренд, название, цвет и раскладка камер для запасной «нарисованной» панели) и запустите `npm run data`.

В каталоге сейчас 28 моделей Samsung, Apple, Google, Xiaomi, OnePlus, Vivo и Oppo. Данные собраны из открытых источников (в первую очередь со страниц сравнений NanoReview, а также Geekbench, AnTuTu, 3DMark, DxOMark) по состоянию на ноябрь 2026.

## Фото телефонов

Для каждого телефона в `public/phones/` лежат две вырезки: `<id>-front.webp` (спереди) и `<id>-back.webp` (сзади); id — как в `src/data/phones.json`. Откуда взят каждый снимок — в [research/photo-sources.md](research/photo-sources.md). У шести моделей Samsung это официальные кадры магазина Samsung, у iPhone «спина» — композиция с сайта Apple, у остальных — галереи Kimovil. В композициях «спина + экран» вид сзади показан вместе с экраном, потому что отдельных чистых задних панелей у источников нет. Изображения принадлежат их производителям.

```bash
# вырезать фон (если у исходника нет прозрачности) и подготовить картинку для сайта
node scripts/cutout.mjs исходник.jpg public/phones/<id>-back.webp --upscale=640
# контактный лист из нескольких кадров, чтобы выбрать нужный: <файл> <колонок> <ширина> <высота> <кадры…> («-» — пустая ячейка)
node scripts/make-sheet.mjs лист.png 6 260 280 кадр1.png кадр2.png
```

Скачанные исходники держите в `research/img-src/` — эта папка не попадает в git. После добавления файлов запустите `npm run build`: признак `photo` в данных обновится сам, а телефон без снимков рисуется запасной задней панелью.

## Как считаются оценки

Оценки по шести категориям и итог считаются в браузере из характеристик и замеров (`src/lib/score.ts`).
Это автоматическая модель, а не экспертное мнение: у камеры, например, учитываются сенсор, оптика и видео по спецификациям, а не качество снимков.
Проект не связан с производителями и сайтами-источниками.
